# Brand assets

`logo-original.jpg` is the client's logo as supplied (square JPG, light background around the circle).

Derived files, all cut out of that circle with a transparent background:

| File | Used for |
|---|---|
| `frontend/src/assets/brand/logo-mark.webp` (320 px) | Header, footer, intro, admin (via `Emblem`) |
| `frontend/public/favicon-32.png`, `favicon-192.png` | Browser tab / Android icon |
| `frontend/public/apple-touch-icon.png` | iPhone home-screen icon (on the emerald background) |
| `frontend/public/logo-512.png` | `logo` in the site's structured data (Google) |
| `frontend/public/og-image.jpg` (1200x630) | Link preview on WhatsApp, Facebook, X |

To change the logo, replace these files with the new artwork under the same names. For best quality ask the designer for the logo as a **transparent PNG or SVG** (the supplied JPG limits sharpness on large screens).

Note: the logo spells the name **FAIRY TALE** (two words); the website text currently writes **FAIRYTALE** (one word). Confirm the preferred spelling with the owner and tell me if the site text should change.
