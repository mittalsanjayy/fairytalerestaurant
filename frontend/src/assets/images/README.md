# Client photography

Place the restaurant's own photographs here (interior, entrance, biryani, alfam, kebabs, mocktails, celebrations, games).

Guidelines (used from Phase 2 onward):

- Export as **JPG or WebP**, longest side **2400px** for hero/full-bleed images, **1600px** for gallery images.
- Use lowercase, hyphenated names: `hero-interior.jpg`, `entrance.jpg`, `chicken-biryani.jpg`.
- Only use photos the client owns or has permission to use. Do not download images from Instagram, Zomato or Google without the owner's permission.
- Menu and gallery images that the administrator uploads later are stored by the backend (`backend/uploads/`), not here.

## File names used by Phase 3

- Menu: `menu-biryani`, `menu-alfam`, `menu-kebabs`, `menu-tikka`, `menu-mocktails`
- Celebrations: `celebration-birthday`, `celebration-anniversary`, `celebration-family`, `celebration-friends`
- Gallery: `gallery-01`, `gallery-02`, ... (any `gallery-*` file is picked up automatically; names sort numerically)
